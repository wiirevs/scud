# Scud Race for Wii

Scud Race (Sega, 1996, Arcade), ported to the Nintendo Wii by [WiiRevs](https://wiirevs.com).

This is a native port, not an emulator: the game's own program runs as native Wii code.

## Download

Get `scud.zip` from [Releases](../../releases/latest).

## Bring your own ROMs

WiiRevs doesn't include or link to any game ROMs. You need the game's ROM files, as a MAME set, dumped from a board you own.

## Install

1. You need a Wii with the [Homebrew Channel](https://wiibrew.org/wiki/Homebrew_Channel) and a FAT32 SD card. [Wii Hacks Guide](https://wii.hacks.guide) explains how.
2. Unzip `scud.zip` to the root of the SD card. That gives you `apps/scud/`.
3. Copy your ROM files into `sd:/wiirevs/scud/`.
4. Start Scud Race from the Homebrew Channel.

No room on the card? The game's folder can go on a USB drive instead, as `usb1:/wiirevs/scud/` (the app stays on the SD card). When both have it, the SD card's is used.

The game checks its files when it starts and lists any that are missing or wrong.
